# LibreELEC Backupper v1.4.1.7 (TEST RELEASE)

## What changed
- Added toggleable verbose logging that elevates debug details to the Kodi log (enabled by default for this build).
- Expanded diagnostic logging across backup creation, uploads, and remote connection flows.
- Keeps prior fixes intact while focusing on log visibility for field testing.

## Notes
- This build is intended for troubleshooting; disable "Verbose debug logging" in settings after testing if you want quieter logs.
